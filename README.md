Title:Mall Customer Segmentation Data
I worked on the 60-customer Mall Customer Segmentation dataset in Excel to make it clean and consistent. First, I checked for missing values in important columns like Country and Spending Score using =COUNTBLANK(A2:A61) and filled the blank numeric cells with the column average or median. For text fields such as Country, I manually corrected the missing entries and converted all names to uppercase using =UPPER(G2) to maintain uniformity. Extra spaces in text columns were removed with =TRIM(A2), and categorical values like Gender were standardized to Male or Female. I removed duplicate rows using Excel’s Remove Duplicates feature so that every CustomerID was unique. For any remaining blank cells, I applied the formula =IF(ISBLANK(A2),"Default Value",A2) to automatically fill them. I also aligned numeric columns like Age and Spending Score to the center for better readability. Finally, I carefully verified the entire dataset to ensure no missing or inconsistent values remained and saved the cleaned version in both .xlsx and .csv formats. Now the dataset is fully cleaned, consistent, and ready for analysis or GitHub upload.
